# Личное портфолио

Статический сайт на HTML, CSS и JavaScript, готовый для GitHub Pages. Серверная часть, сборщик и внешние библиотеки не нужны. Шрифты, фотографии и иконки хранятся локально. Контакты: Telegram `@mars_better`, телефон `+77002850261`.

## Просмотр

Из этой папки запустите `python -m http.server 8000`, затем откройте http://127.0.0.1:8000/. Можно также открыть index.html напрямую; копирование профиля зависит от разрешений браузера.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в его корень содержимое этой папки, включая `.github/workflows/pages.yml`.
2. В Settings → Pages выберите Source: GitHub Actions.
3. Отправьте изменения в ветку `main`. Workflow загрузит статический сайт и опубликует его через Pages.

Адрес сайта: https://ebzik-nvrm.github.io/ . Репозиторий: https://github.com/ebzik-nvrm/ebzik-nvrm.github.io . Сайт использует относительные пути, подходящие для GitHub Pages.

## Содержание и управление

- Образование: окончание 11 классов в 15 лет, СЛОД №20, текущий 4 курс IITU.
- Роль: световая схема связи бизнес-задачи с технологиями, процессами и людьми. Кнопка паузы и поддержка prefers-reduced-motion.
- Опыт: четыре раскрывающихся раздела.
- Программы: десять кнопок с пояснениями опыта, без выдуманных оценок владения.
- Личная история: результат −30 кг за 5 месяцев со слов автора, два месяца изучения вопроса; переключатель архивной и нынешней фотографии. Начальные и конечные значения веса, даты и медицинские выводы не добавлялись.
- Контакты и краткий профиль: рабочие ссылки, диалог с возвратом фокуса и копированием текста.

## Обновление

Тексты и изображения — index.html, оформление — styles.css, интерактивность и описания инструментов — script.js. После правок увеличьте версию в URL CSS/JS в index.html для обновления кэша. Источники ресурсов — assets/credits.md.

Возраст и курс указаны по данным автора на сентябрь 2026 года. Имя и фамилия пока не предоставлены, поэтому в шапке используется авторский знак и формулировка «человек & системы».
